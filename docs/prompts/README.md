# User Prompt Archive

Important user prompts are archived here (plain text/markdown, searchable) because a single prompt
may contain multiple details not fully represented by the final implementation (e.g. two bugs + one
visual correction + one feature request + one behavior rule + one Figma comparison). If prompts
disappear, the original intent is lost.

This archive does NOT replace proper documentation — it is the historical reference showing
**how and why the user guided the AI toward a certain result.**

## Naming & indexing

File name: `YYYY-MM-DD_NNN_short-slug.md`. Every entry starts with this index header:

```text
Date:
Task ID:
Feature:
Subsystem:
Related Bug:
Keywords:
Related Documentation:
```

Followed by the user's prompt (verbatim where possible) and optional context notes.

Entries so far: `2026-10-11_001_fresh-project-ingest.md` (the founding prompt of this project).
