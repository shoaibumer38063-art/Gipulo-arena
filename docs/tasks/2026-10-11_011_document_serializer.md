# Task 011 — Document serializer (`gip-document`, roadmap step 11)

**Date:** 2026-10-11 · **Status:** COMPLETE (native tests, clippy, fmt, boundary check, wasm check green) · **Governs:** `docs/architecture/ADR-003-file-format.md` (amendments A1–A6) · `document-tree.md` §2–§3 · `CAN-SER` rules

## Goal

Build the persisted document schema and the `.gip` v1 container with validation and canonical
serialization, test-first. No transaction API, no UI, no asset bytes.

## What was built

| File | Contents |
|---|---|
| `id.rs` | `NodeId`/`AssetId` (`salt(24)<<40 \| counter(40)`), strict 16-hex serde, `hex64` adapter |
| `transform.rs` | `Transform` (ADR-002 field names, `deny_unknown_fields`, `validate`) |
| `path.rs` | serde derives on the ADR-006 model; `Path::validate_finite` |
| `node.rs` | `NodeKind` (kebab-case, `is_container`), `Node` with `ext` |

| `file.rs` | `GipFile`, `Meta`, `AssetRecord`, `to_json`, `from_json`, migration table |

| `gip-geometry/src/bridge.rs` | `trs_of` / `transform_of` (exhaustive destructuring, drift guard) |

## Validation rules (all tested as rejections)

Id salt equals `docSalt` · counter below `nextId` · no duplicate ids · child references resolve ·
each node referenced exactly once · no orphans · children only on containers · `VectorPath` ⇔
path payload · transform finite, sizes ≥ 0, rotation in (−180, 180] · opacity in [0, 1] · no
non-finite path coordinates · asset ids in lineage space and not colliding with document ids ·
asset hash = 64 lowercase hex.

## Decisions

ADR-003 amendments A1–A6 (see the ADR's "Implementation amendments" section): hex-string IDs;
`ext` scope; asset id space; `documentHash` written `null` until its dependency is registered;
validate-then-write; forward-only migrations.

## Dependencies

`serde` (derive) and `serde_json` (`float_roundtrip`) — the registered layer-1 exception
(`dependencies.md` §2–§3). Transitive crates: `serde_core`, `serde_derive`, `itoa`, `memchr`,
`zmij`, `proc-macro2`, `quote`, `syn`.

## Bugs caught during the phase (recorded for the regression record)

1. Orphan-test fixture used an id above `nextId`, so the counter rule fired first. Fixed by setting the test's `nextId`.
2. Asset id reused counter 1 (same value as a page id); the validator did not check the asset id space. Fixed by adding rule A3 with a test.
3. Error messages printed `NodeId(…)` debug output. Fixed with a hex `Display` impl.
4. `impl Path` appended after the test module (clippy `items_after_test_module`). Moved above.
5. Sample `nextId` was not raised when the asset counter changed. Fixed in the fixture.

## Deferred (explicit)

`documentHash` (SHA-256 dependency decision) · NFC normalization (Unicode dependency decision) ·
asset store and bytes · transaction API (SM3) · observation/subscriptions · `trs_of` drift test for
`Trs` ↔ `Transform` beyond exhaustive destructuring (done by construction).
