**Approach selected (each decision + why, full tables in the ADRs):**

1. **ADR-002 — transforms/numerics.** Canonical transform = decomposed fields
   (x·y·w·h·rotation·flipH·flipV, all f64; sizes ≥ 0). Matrices are derived caches in the
   browser-native column-major 6-tuple order (zero re-ordering at CSS/SVG/Canvas2D handoffs).
   Composition `T·R·S` with the local origin at the node's top-left (CSS `transform-origin: 0 0`);
   gesture pivots stay in the ONE pivot calculator. Rotation = degrees normalized to (−180, 180]
   everywhere. Flip = flags (confirms CAN-TR-5 [PROPOSED]); zero-crossing flips DURING preview so
   preview/commit equivalence holds by construction; no hidden minimum sizes (0-size nodes are
   legal but inert). No skew in v1 (ADR + migration if ever). No math crate: hand-rolled `Mat2`/
   `Vec2` in `gip-coords`. ONE constants module (`EPS_ROUNDTRIP 1e-9` world units · `EPS_ANGLE`
   · `EPS_MATRIX`). 3D stays out (affine 2×3; future 3D ADR owns its 4×4).
2. **ADR-003 — `.gip` v0.** Single-file UTF-8 JSON, schema-declared field order, ALL fields
   explicit, BTreeMap collections, NFC strings, no time/random in content — byte-identical output
   across runs is the golden law. f64 as shortest round-trippable decimals (`ryu`) — bit-exact
   round-trip; NaN/Inf schema-invalid. IDs = u64 (`salt(24)` + `counter(40)`), salt in `meta`,
   `nextId` stored; **cross-lineage merges must remap IDs** (the law that makes 64-bit IDs safe
   without collab-grade 128-bit). Assets: sidecar content-addressed store (SHA-256) + manifest;
   immutable in v0; no blobs inside the JSON. Forward-only migrations; unknown fields preserved at
   bounded `ext` points. `meta.documentHash` for integrity + golden tests. NOT in the file:
   selection/camera/hover/undo stack. TS types hand-mirrored + cross-language fixture test (no
   codegen machinery yet). No compression in v0 — a measured, separate later decision.
3. **ADR-004 — history.** Entries = structured op logs (`SetField` · `InsertNode` · `RemoveNode` ·
   `MoveNode` · `ReorderChildren` · `SetShared` · `SetMeta`) with recorded `before`/`after`
   payloads; undo replays recorded values — mutators are NEVER re-executed (session-independent
   correctness, byte-identity tests by construction). Commands and snapshots explicitly rejected
   with reasons. Nested transactions fold; truncate redo tail on edit-after-undo; byte-budget cap
   (64 MiB [PROPOSED], measured) with oldest-drop degradation; text coalescing on 500 ms pause /
   focus loss; in-memory only in v1 (`markSaved` = entry index + document hash); op-log shape is
   the collab-non-precluding answer with zero speculative code.
